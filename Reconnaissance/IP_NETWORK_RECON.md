# IP & Network Reconnaissance

IP and Network Reconnaissance is the process of identifying and gathering information about IP addresses, network ranges, hosts, and network infrastructure associated with an authorized target .

It helps cybersecurity professionals understand how systems are connected and identify the external network attack surface before performing further security testing.

## What is an IP Address?

An IP address is a numerical address used to identify a device on a network.

There are two main versions:

- IPv4
- IPv6

### IPv4

IPv4 addresses contain four numerical sections separated by dots.

Example:

192.168.1.10

### IPv6

IPv6 uses a hexadecimal format and provides a much larger address space.

Example:

2001:db8::1

## Public vs Private IP Addresses

### Public IP Address

A public IP address is routable on the Internet and can be associated with publicly accessible services.

Example:

203.0.113.10

### Private IP Address

Private IP addresses are used inside local networks and are not directly routable across the public Internet.
