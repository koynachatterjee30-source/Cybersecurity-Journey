# Reconnaissance Tools

Reconnaissance tools are used by cybersecurity professionals to collect, analyze, and organize information about an authorized target.

These tools help with tasks such as OSINT, DNS enumeration, subdomain discovery, network scanning, service identification, and technology fingerprinting.

## Why Reconnaissance Tools are Important

Manual information gathering can take a lot of time. Reconnaissance tools help automate repetitive tasks and make security assessments more efficient.

They can help identify:

- Domains
- Subdomains
- IP addresses
- DNS records
- Open ports
- Running services
- Technologies
- Publicly available information
- Network infrastructure
- Web application information

## 1. Nmap

Nmap (Network Mapper) is a network discovery and security auditing tool.

It can be used to:

- Discover hosts
- Scan ports
- Identify services
- Detect service versions
- Perform basic OS detection
