# Web Reconnaissance

Web Reconnaissance is the process of collecting information about a web application before performing authorized security testing. It helps security professionals understand the structure, technologies, endpoints, files, and publicly accessible information associated with a website.

Web reconnaissance is an important part of VAPT and penetration testing because it helps identify the application's external attack surface.

## Why Web Reconnaissance is Important

Web reconnaissance can help identify:

- Web technologies
- Web servers
- Frameworks
- CMS platforms
- Subdomains
- Web pages
- API endpoints
- Publicly accessible files
- HTTP headers
- Cookies
- SSL/TLS information
- Security headers
- Directories and resources

The collected information can help security professionals determine what should be assessed further.

## Web Reconnaissance Methodology

A basic web reconnaissance process is:

1. Identify the authorized target
2. Collect basic domain information
3. Identify the web server
4. Identify technologies
5. Analyze HTTP headers
6. Check publicly available files
7. Identify directories and endpoints
8. Examine JavaScript files
9. Review cookies and security headers
10. Document the findings

## HTTP and HTTPS

HTTP stands for Hypertext Transfer Protocol.

HTTPS is HTTP secured using TLS (Transport Layer Security).

HTTPS helps protect data exchanged between a client and server by providing encryption and authentication.
