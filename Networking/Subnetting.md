# Subnetting

## What is Subnetting?

Subnetting is the process of dividing a large network into smaller and more manageable networks called subnets.

## Why is Subnetting Used?

- Improves network performance
- Reduces network congestion
- Enhances security
- Makes IP address management easier

## Key Terms

### Subnet Mask
A subnet mask is used to identify the network and host portions of an IP address.

Example:
- IP Address: 192.168.1.10
- Subnet Mask: 255.255.255.0

### Network Address
The first address of a subnet.

### Broadcast Address
The last address of a subnet used to send data to all devices in the network.

### Host Address
Addresses assigned to devices within a subnet.

## CIDR Notation

- /24 = 255.255.255.0
- /25 = 255.255.255.128
- /26 = 255.255.255.192
