# Routing

## What is Routing?

Routing is the process of forwarding data packets from one network to another using a router. It helps data find the best path to reach its destination.

## What is a Router?

A router is a networking device that connects different networks and forwards packets based on IP addresses.

## Types of Routing

### Static Routing
- Routes are manually configured by the administrator.
- Suitable for small networks.

### Dynamic Routing
- Routes are learned automatically using routing protocols.
- Suitable for large networks.

## Routing Protocols

### RIP (Routing Information Protocol)
- Uses hop count as a metric.
- Maximum hop count is 15.

### OSPF (Open Shortest Path First)
- Uses cost as a metric.
- Faster and more efficient than RIP.

### EIGRP
- Cisco proprietary protocol.
- Supports fast convergence.

## Routing Table

A routing table contains information about network destinations and the paths used to reach them.
