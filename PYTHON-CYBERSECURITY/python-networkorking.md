# Python Networking

Python networking is the use of Python to communicate with computers, servers, and network devices over a network.

**What I learned:**

* Understanding IP addresses, ports, TCP and UDP
* Creating network connections using Python sockets
* Building simple TCP client-server programs
* Sending and receiving data over a network
* Working with DNS and resolving domain names
* Making HTTP/HTTPS requests using the `requests` library
* Checking whether a host or port is reachable
* Using Python to automate basic network tasks
* Handling network errors and connection timeouts

**Important Modules & Libraries:**

* `socket` – Network connections and TCP/UDP communication
* `requests` – HTTP/HTTPS requests
* `urllib` – Working with URLs
* `subprocess` – Running network commands
* `ipaddress` – Working with IP addresses and networks

**Mini Projects:**

* TCP Client-Server
* Website Status Checker
* IP Address Information Tool
* DNS Lookup Tool
* Basic Port Checker

**Skills:** Python • Networking • TCP/IP • Sockets • HTTP/HTTPS • DNS • Network Automation

**Goal:** Use Python to understand, automate, and troubleshoot network-related tasks for system administration and cybersecurity.
